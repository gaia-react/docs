A skill is a folder of instructions that Claude loads when your request matches it. Each skill has a `SKILL.md`, and some have extra files in `references/` that Claude reads only when it needs them. GAIA ships skills in two places:

- **`.claude/skills/`** at the project root: skills that apply anywhere in the repository.
- **`frontend/.claude/skills/`**: the React app's skills, which load in sessions working on the app.

[React Doctor](https://github.com/millionco/react-doctor) is installed on each machine separately, at `frontend/.claude/skills/react-doctor`, and is gitignored. GAIA's workflow commands (`/gaia-spec`, `/gaia-plan`, and the rest) read their instructions from `.claude/skills/gaia/references/`. That folder is not a skill you can call with a slash command.

## How triggering works

Each `SKILL.md` has a `description:` field listing the phrasings and situations that load it. A skill loads when that description matches what you said, not on every prompt. Saying "scaffold a card called price-card" loads `new-component`; saying "this useEffect fires twice" loads `react-code`.

`/gaia-wiki`, `/update-deps`, and `/update-gaia` are skills, so asking in plain English triggers them too. They also appear in the statusline (`🧠`, `📦`, `🚀`) when they have work to do.

Some commands are user-only: `/gaia-init`, `/setup-gaia`, `/gaia-fitness`, `/gaia-forensics`, `/gaia-codify`, `/gaia-residue`, and `/gaia-serena-sync`. They set `disable-model-invocation`, so Claude never starts them on its own and they do not appear in its list of skills. Type them yourself as slash commands.

## Questions are menus

When a GAIA skill or command needs you to choose, it shows a menu (`AskUserQuestion`) with the recommended option first. The shipped `user-questions` rule holds the skills you write to the same standard. A separate rule, `context-discipline`, prints any prompt or command meant for you to paste in a fenced code block.

## Adding your own

Add a folder under `.claude/skills/<name>/` (or `frontend/.claude/skills/<name>/` for a skill only the app needs) with a `SKILL.md`. Its frontmatter sets `name` and `description`, and optionally `model:` to always run the skill on a particular model. Claude picks it up in the next session. [`/gaia-fitness`](/maintenance/fitness/) lints it.
